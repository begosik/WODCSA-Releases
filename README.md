# War of Doctrines Releases

Здесь выходят сборки WoD и лаунчера для Red Alert 3 1.12. [Открыть релизы](https://github.com/begosik/WODCSA-Releases/releases)

Для первой установки скачайте полный архив `WOD-Launcher-2.0c-win64.zip`, распакуйте его и запустите `WOD Launcher.exe`. В лаунчере выберите язык игры и нажмите «Скачать», чтобы установить WoD. Архив `WoDLauncher.zip` используется для автообновления.
